# research/

One-off analysis for the project's **pre-registered tests**. Nothing here
runs on a schedule and nothing here touches the site.

⛔ **Read `claude/owed-tests.md` before running or changing any of it.**
Every test in here has a specification and a pass bar that were fixed
BEFORE it was run. **A script that is edited after seeing its own result
is no longer the test that was registered.**

## T27 — the first hitter model (P(1+ hit))

**RESULT 2026-08-24: FAILED.** Brier improvement over the shipped estimator
was **+0.00236** against a pre-registered bar of **+0.00500**. The bar was
not moved. **Nothing shipped** — hitter rows on the Picks tab still carry
the smoothed season rate and still carry no confidence rating.

```
python research/t27_data.py     # build the point-in-time rows
python research/t27_fit.py      # fit + evaluate (one specification)
python research/t27_verify.py   # prove the pipeline before trusting it
```

`t27_rows.json` is regenerated by the first script and is deliberately not
committed — it is derived data, and a stale copy is worse than none.

**The finding worth keeping is not the failure.** Plate appearances carry
roughly **3.5x** the weight of hitting rate (β 0.258 vs 0.073 per SD), and
the shipped estimator ignores them entirely. Home/road is **null for
hitters** (z = −1.47) despite being significant for pitchers. T28 is
registered to follow up on the first of those.
