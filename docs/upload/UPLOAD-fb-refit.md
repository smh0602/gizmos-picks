# UPLOAD BY HAND: `fb-refit.yml` (the football model's weekly contest)

**Do this after the pull request "Football: weekly champion vs challenger and
scoreboard (T65)" is merged.** It takes about 2 minutes. Nothing else is needed
afterwards: the job runs every Monday at 09:47 UTC by itself, and the Monday
status email (11:17 UTC) reads what it wrote.

1. The file to upload is on your PC at:
   `C:\Users\Senor\gizmos-picks\docs\upload\fb-refit.yml`
   (on GitHub: https://github.com/smh0602/gizmos-picks/blob/main/docs/upload/fb-refit.yml,
   **Download raw file**).
2. Go to **https://github.com/smh0602/gizmos-picks/tree/main/.github/workflows**
3. Check the breadcrumb at the top of the file list reads
   **gizmos-picks / .github / workflows**. If it doesn't, go back to step 2.
4. Click **Add file** (top right, next to the green Code button), then
   **Upload files**.
5. Click **choose your files**, the blue link in the middle of the box.
   ⛔ Don't drag the folder in.
6. In the file picker, go to `C:\Users\Senor\gizmos-picks\docs\upload\`,
   click **fb-refit.yml**, and click **Open**.
7. Check the page lists exactly one file: **fb-refit.yml**.
8. In the **Commit changes** box, put this in the first line (paste it):

```
fb-refit: weekly football champion vs challenger, uploaded by hand (cron block)
```

9. Leave **Commit directly to the main branch** selected.
10. Click the green **Commit changes** button.

That's all. 💰 No cost: it reads only the repo's own files.
